# instrumentation-bunyan
Nodejs OpenTelemetry instrumentation for bunyan package in nodejs

## Background

This instrumentation is forked from opentelemtry, written be [Odigos team](https://github.com/odigos-io/odigos) to fix an issue with the original [bunyan instrumentation in contrib](https://github.com/open-telemetry/opentelemetry-js-contrib/tree/main/plugins/node/opentelemetry-instrumentation-bunyan).

It is planed to be ported to upstream some time in future once it's verified.
